This section covers the preset information returned by [`Project:GetProjectSettingsPresetList`](../resolve_api/Project.md#getprojectsettingspresetlist), which returns a list of dictionaries, one per project settings preset.

Each dictionary contains the following keys:

`Name`: string (preset name)

`Width`: int (resolution width, example: 1920)

`Height`: int (resolution height, example: 1080)
